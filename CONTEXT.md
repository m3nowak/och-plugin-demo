# Rat demo

A demo extension for OpenChamber that presents a rotating rat model.

## Language

**Rat**:
The demo's user-facing name in OpenChamber.
_Avoid_: Szczur, Low Poly Rat as the plugin name.

**Extension**:
An add-on to OpenChamber, such as Rat. It is distinct from an OpenCode plugin.
_Avoid_: OpenCode plugin when referring to Rat.

**Rail panel**:
An OpenChamber panel accessed through an entry on the application's rail. Its dock position belongs to the host layout, not the extension's identity.

**Rat model**:
The "Low Poly Rat" 3D artwork by Tyler Lazzareschi, distinct from the Rat extension itself.

**Model attribution**:
Credit for the rat model's creator, source, and license. It is distinct from the license for the plugin's own code.
